# Asteroid War em Python

Versão escolar experimental. Execute `pip install -r requirements.txt` e `python main.py` nesta pasta. Para navegador, execute `python -m pygbag .` e abra o endereço exibido. Controles: WASD/setas, espaço ou controles de toque. A versão mantém recorde local durante a execução; integração de contas/ranking online e persistência do HUD ainda pendentes. Tela cheia depende do ambiente. Não é uma substituição do servidor web existente.
